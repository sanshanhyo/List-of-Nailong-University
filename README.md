# 奶龙高校联盟

这里是 **奶龙高校联盟**！

本项目旨在收集、整理并展示各高校的奶龙相关内容，包括但不限于：

- 🐉 **校园内出没的奶龙**：记录校园各个角落出现的奶龙！
- 🎨 **奶龙变体**：收录来自不同高校、具有校园特色的奶龙形象！
- 🌐 **奶龙访问入口**：收集各高校的奶龙主题域名与网站！

本项目灵感来源于 [原神高校联盟](https://github.com/cokice/List-of-genshin-University)

如果你喜欢这个项目，欢迎点亮 ⭐ Star！

## 📮 提交方式

我们欢迎来自全国乃至世界各地高校的奶龙投稿！

### A. 通过 GitHub Issue 提交（推荐）

1. 点击 [提交奶龙](https://github.com/sanshanhyo/List-of-Nailong-University/issues/new/choose)。
2. 选择投稿类别。
3. 填写学校名称、相关介绍，并附上图片/链接。
4. 提交 Issue，等待审核。

审核通过后，我们会将内容收录至对应名单。

### B. 通过 Pull Request 提交

熟悉 GitHub 的贡献者可以直接提交 PR。

1. Fork 本仓库。
2. 根据对应类别修改或添加收录内容。
3. 提交 Pull Request。
4. 等待检查与审核，通过后合并。
